FOX-983 · A/B Test Prototype

Perbandingan Alur Tracer Study

Piloting untuk menyederhanakan skema Tracer Study dari model saat ini (Admin membuat banyak kuesioner terpisah per angkatan/gelombang) menuju model single-questionnaire seperti tracerstudy.kemdikbud.go.id. Dua skenario di bawah adalah prototype yang dibandingkan sebelum PM memutuskan arah development final.

A

Alur Sederhana

Sekali isi, seminimal mungkin langkah admin

Admin membuat 1 kuesioner berbasis tahun lulus (Save as Template). Alumni akses via Gate/karirlink.id, sistem otomatis mengarahkan ke grup sesuai tahun lulus (G1/G2/Exit), lalu isi kuesioner step-by-step via Wizard.

  • Tidak ada Template Version maupun Campaign - susun, simpan, kirim (3 langkah)
  • Wave dihitung otomatis dari tahun lulus, read-only
  • Tidak ada opsi edit setelah submit (terminal, terkunci)

B

Alumni Dapat Isi Kembali/Edit

Data selalu up-to-date, admin tetap punya kontrol granular

Sisi admin tetap seperti fitur asli /v2/ (Template Version + Campaign per institusi+wave+cohort_year, tanpa perubahan). Satu-satunya perubahan ada di sisi alumni: alumni bisa melihat riwayat pengisian dan mengedit/mengisi kembali response yang sudah pernah dikirim.

  • Sisi admin identik dengan /v2/ (Template Version + Campaign, tidak diubah)
  • Alumni punya halaman Riwayat Pengisian lintas wave
  • "Edit Jawaban" tersedia selama campaign masih aktif
